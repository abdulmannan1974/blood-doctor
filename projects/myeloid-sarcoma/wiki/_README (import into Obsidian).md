# 📥 How to use this wiki in Obsidian

This folder is a self-contained **Obsidian deep wiki** on **Myeloid Sarcoma of the Breast**. All notes are plain Markdown using Obsidian-native features (callouts, `[[wikilinks]]`, tables, Mermaid, frontmatter) — **no plugins required**.

## Option A — drop into an existing vault
1. Copy the entire **`wiki/`** folder into your vault, e.g. `…/My Vault/Haematology/Myeloid Sarcoma of the Breast/`.
2. Open Obsidian → it indexes the notes automatically.
3. Start at **[[Myeloid Sarcoma of the Breast]]** (the MOC/home note) and use the **Graph view** to see the link web.

## Option B — open as its own vault
1. In Obsidian: **Open folder as vault** → select this `wiki/` folder.

## ✅ Features used
- **Coloured callouts:** `[!abstract] [!tip] [!note] [!info] [!success] [!warning] [!failure] [!danger] [!quote] [!example] [!important] [!question]`
- **Mermaid algorithms:** diagnostic & treatment flowcharts, genetics decision flow (render natively).
- **Tables** for IHC panels, genetics, differentials, RT doses, outcomes.
- **Wikilinks** between all notes for a true "deep wiki" graph.
